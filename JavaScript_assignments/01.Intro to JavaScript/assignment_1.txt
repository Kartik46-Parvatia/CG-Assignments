Ques. 8

Dynamic Typing in JavaScript means that the interpreter assigns a data type to a variable at runtime based on its value at that moment, rather than requiring you to explicitly define the type beforehand. In a dynamically typed language, data types are associated with the values themselves, not the variable names.


Ques. 9

The main difference between a Static and Dynamic Website is that a static website delivers prebuilt files that look the exact same for every visitor, whereas a dynamic website generates content in real time using databases and server-side code to customize the experience for each user.


Ques. 10

The three pillars of front-end web development are HTML, CSS, and JavaScript.

(1) HTML (HyperText Markup Language): HTML gives content its structure by defining elements like headers, paragraphs, lists, and links.
(2) CSS adds visual styling, color, layout, and spacing to make web pages look neat and professional.
(3) JavaScript: JavaScript introduces dynamic behavior and interactivity, handling user events like clicks, animations, and live data updates.


Ques. 11

The frontend is the client-side part of a website or app that users see and interact with directly, while the backend is the server-side infrastructure that handles data, logic, and database operations behind the scenes.

FRONTEND-- Definition: The visible part of a website or app that users touch, view, and navigate.
            Purpose: Ensure a user-friendly, responsive, and visually pleasing experience across all devices.
            Technologies: HTML, CSS, JavaScript, and frameworks like React, Angular, or Vue.
            Examples: Buttons, forms, menus, images, and text layouts

BACKEND--  Definition: The hidden engine that powers an application, consisting of servers, applications, and databases.
            Purpose: Process user requests, manage business logic, secure data, and handle storage and retrieval.
            Technologies: Python, Java, PHP, Ruby, Node.js, and databases like MySQL, PostgreSQL, or MongoDB.
            Examples: User authentication, payment processing, database updates, and server communication via APIs.


Ques. 12

Node.js is a free, open-source, cross-platform JavaScript runtime environment that allows developers to execute JavaScript code outside of a web browser.
Before the creation of Node.js, JavaScript was primarily restricted to running inside web browsers (client-side) to make websites interactive. Node.js shifted this paradigm by enabling JavaScript to run directly on a local machine or server. It is built on Google Chrome's high-performance *V8 JavaScript engine* and natively supports both JavaScript and TypeScript
